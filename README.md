## 买之前先确定两件事：机房位置和产品形态

机房位置排在所有参数之前。外贸独立站的客户在海外，机房离客户越近，网页打开越快——目标客户在北美就选美国机房，集中在美国西部就优先洛杉矶。这条原则直接决定访问速度，而速度影响转化。

产品形态也决定了你要不要走到“买服务器”这一步。市面上常见三条路：

- **托管建站平台**：Shopify、Shopline 这类把服务器和运维全包了，按月付订阅费。不想碰任何技术环节，走这条路就行，不需要看下去。
- **高端托管主机**：如 Kinsta，走 WordPress 路线但托管化，后台直接建站，代价是月费明显更高，适合有预算、想省事的团队。
- **VPS（虚拟专用服务器）**：一台物理服务器虚拟切分，你拿到独立的 CPU、内存和 root 权限，自己装环境。价格低、自由度高，运维靠自己。

对预算有限、愿意自己动手的独立站卖家，VPS 是成本最低的自建方案。RackNerd 属于这一类，下面的内容都围绕它展开。

## 常见问题

**独立站一定要自己买服务器吗？**
不一定。Shopify 等托管平台把服务器包在订阅费里，不动手折腾就选它们。只有走 WordPress 自建路线、或者需要把网站数据完全握在自己手里时，才需要买服务器。自建的好处是成本可控，一年几十美元就能跑起来。

**流量 3TB / 5TB 够独立站用吗？**
